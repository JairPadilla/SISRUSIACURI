Exportar base de datos

Descarga una copia completa del sistema a este computador.

  • Usuarios, gestores y asignaciones
  • Líneas estratégicas, programas y productos
  • Avances reportados y sus evidencias
  • Marca institucional (nombre y logo)
El archivo se descarga como sisr_respaldo_AAAA-MM-DD_HHMMSS.db. Guárdalo en un lugar seguro, por ejemplo una memoria USB o la nube institucional. Además queda una copia en el servidor (carpeta respaldos) y aparece en el historial.

Importar base de datos

Restaura el sistema desde un archivo de respaldo.

Arrastra aquí el archivo de respaldo Formato .db · tamaño máximo 100 MB
Atención: al importar se reemplaza toda la información actual. Antes de restaurar, el sistema guardará automáticamente una copia de la base vigente.
